Visual File Transfer

Send a file through a video call.

No upload, no install, no account. The file crosses as flashing QR codes on a shared screen, and arrives checked.

How it works

What to know

Nothing leaves the page

Each page is one file with a Content-Security-Policy of default-src 'none'. The browser itself refuses every network request, so the file only travels over the call.

Checked, not trusted

The receiver verifies the SHA-256 digest before it offers Save. Any contradiction in what it sees is shown as an error and never as a success.

Slow, on purpose small

About 400 bytes per second in the one real call it was measured on. Good for notes, configs, and small PDFs; not for video.

Tested end to end over Google Meet on 2026-08-04: a 69,466-byte PDF arrived byte-identical. Source and notes: github.com/tg-techie-agents/vft. Built on open-source components.
