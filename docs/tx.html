How to run a transfer
  • Share this window (not the whole screen) on the video call; keep it as large as possible, avoid overlays.
  • Start the Rotation. The RX Operator watches with the RX Client.
  • When a Rotation or two has passed, ask the RX Operator for a Gap Report over chat, paste it here, Apply.
  • A report ending in - means nothing is missing: you can stop.
  • If Symbols fail to decode on the far side: increase Slice interval or reduce Slice size.
